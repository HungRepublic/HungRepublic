### 🚀 About Me

I am a **Data Engineer** specializing in architecting resilient, high-throughput distributed data platforms and real-time streaming pipelines. My core focus lies in **stateful stream processing**, **asynchronous change-data-capture (CDC)**, and **large-scale data lakehouse transformations** on Kubernetes.

- 🔭 **Focus Areas:** Real-Time Stream Processing, Lakehouse Architecture, CDC & Event Orchestration, Automated Data Reconciliation.
- ⚡ **Engineering Principles:** Zero-data-loss streaming, sub-second latency, deterministic checkpoints, and automated self-healing distributed data pipelines.
- 🛠️ **Infrastructure:** Native Kubernetes deployment, Docker containerization, Helm, and declarative Jenkins CI/CD pipelines.
